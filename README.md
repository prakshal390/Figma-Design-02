# ZiniGo — Bhutan Travel Landing Page 🏔️✨

A pixel-perfect, responsive React & Tailwind CSS implementation of the **ZiniGo** landing page UI design based on the official Figma specifications.

---

## 🚀 Features

* **Pixel-Perfect UI**: Carefully matched typography, colors, and layout directly from the Figma design.
* **Fully Responsive**: Fluid layout supporting mobile, tablet, and desktop screens.
* **Interactive FAQ Accordion**: Toggleable accordion with smooth transitions and active states.
* **CTA & Footer Section**: Custom WhatsApp and "Get Free Quote" CTA components, styled social links, and legal navigation.
* **Accessible & Semantic HTML**: Proper ARIA roles, labels, and semantic markup for SEO and screen readers.

## 💻 Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisites

Ensure you have the following installed:

* [Node.js](https://nodejs.org/?utm_source=gemini) (v16.x or higher)
* `npm` or `yarn`

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/your-username/zinigo-landing-page.git
cd zinigo-landing-page

```


2. **Install dependencies**
```bash
npm install
# or
yarn install

```


3. **Install Lucide Icons (if not included in setup)**
```bash
npm install lucide-react

```


4. **Run the development server**
```bash
npm run dev
# or
yarn dev

```


5. **Open in browser**
Navigate to `http://localhost:5173` (or the port specified in your terminal) to view the application.
